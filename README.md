# Fr3oon Helper Bot V11 — Smart Cards

التحديثات الجديدة:
- قراءة أدق لوقت وتاريخ البطاقة من سطر التاريخ نفسه.
- لو التاريخ اتقرأ بدون وقت، يستخدم وقت إرسال الصورة بدل 00:00.
- منع تكرار نفس رمز الاستبدال حتى لو الصورة مختلفة.
- رفض الأكواد المنتهية بعد 3 أيام.
- إظهار الوقت المتبقي على انتهاء الكود.
- زر «تم الاستبدال» لصاحب البطاقة أو الأدمن فقط.
- تنسيق رد أنظف، والكود قابل للنسخ.
- رسالة فشل قراءة مختصرة.
- أمر `/stats` للأدمن لعرض إحصائيات البوت منذ آخر تشغيل.
- منشورات القناة المرتبطة ما زالت مستثناة حتى تظل التعليقات شغالة.

## ملاحظة مهمة
منع التكرار والإحصائيات محفوظان في ذاكرة تشغيل Vercel. قد يتم تصفيرهما عند إعادة النشر أو عند إعادة تشغيل الدالة بسبب طبيعة Vercel Serverless.

## متغيرات البيئة
لا تحتاج إضافة متغيرات جديدة. استمر بالقيم الحالية:

OCR_FROM_IMAGE=true
OCR_PREFER_CLOUD=true
OCR_SPACE_API_KEY=YOUR_KEY
PHOTO_EXPIRY_DAYS=3

بعد النشر افتح `/api/set_webhook` مرة واحدة لأن النسخة الجديدة تضيف `callback_query` لتشغيل زر «تم الاستبدال».
