# Fr3oon Helper Bot V10 - Strict OCR

هذه النسخة تمنع نشر كود خاطئ:
- تقص مكان رمز الاستبدال فقط من صورة بطاقة PUBG.
- تعزل اللون البرتقالي للأرقام.
- تستخدم OCR.Space بمحركين وعلى أكثر من قصاصة.
- لا تنشر الكود إلا بعد اتفاق أكثر من قراءة مستقلة.
- إذا لم تتأكد، لا تخمن ولا تكتب رقمًا غلط.
- التاريخ يُقرأ من الصورة الكاملة ويضاف له 3 أيام.

متغيرات البيئة:
OCR_FROM_IMAGE=true
OCR_PREFER_CLOUD=true
OCR_SPACE_API_KEY=YOUR_KEY
PHOTO_EXPIRY_DAYS=3
