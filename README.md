# Fr3oon Helper Bot V18 — Group Manager

هذه النسخة مبنية مباشرة على V11 المستقرة، ولم يتم تغيير منطق قراءة البطاقات.

## إضافات إدارة الجروب
- رسالة ترحيب للعضو الجديد مع زر: «قرأت القوانين وأوافق».
- تقييد العضو الجديد حتى يوافق على القوانين.
- منع البيع والشراء والتحويلات المالية.
- منع طلب الإيميل، الباسورد، كود التحقق، الهاتف أو بيانات الحساب.
- المخالفات: تحذير أول، كتم 10 دقائق في الثانية، حظر في الثالثة.
- طلب الباسورد أو كود التحقق بصيغة مباشرة = حظر فوري.
- منع الروابط والفورورد والشتائم والسبام وتكرار الرسائل والصور.
- تنظيف رسائل انضمام/خروج الأعضاء ورسائل الخدمة.
- ردود تلقائية للأسئلة المتكررة عن التبادل ومكان استخدام الكود.
- وضع بطيء داخلي لكل عضو.
- قفل وفتح الجروب.
- الإبلاغ عن رسالة بالرد عليها وكتابة `/report`.

## أوامر الأعضاء
- `/rules`
- `/help`
- `/admin`
- `/report` بالرد على رسالة
- `/mywarnings`

## أوامر الأدمن
- `/stats`
- `/slow 30`
- `/normal`
- `/lock`
- `/unlock`

## صلاحيات البوت المطلوبة داخل الجروب
فعّل للبوت:
- Delete messages
- Ban users / Restrict members

بدون صلاحية Ban users لن يعمل: قبول القوانين، الكتم، الحظر، القفل والفتح.

## النشر
1. استبدل ملفات المشروع بهذه الملفات.
2. Commit ثم Push origin.
3. انتظر Vercel حتى Ready.
4. افتح `/api/set_webhook` مرة واحدة.
5. اختبر أولًا في جروب خاص قبل الجروب الأساسي.

ملاحظة: عدادات المخالفات والوضع البطيء محفوظة في ذاكرة Vercel المؤقتة، وقد تبدأ من جديد عند إعادة تشغيل الخادم.
