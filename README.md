# Fr3oon Helper Bot V15 — Full-image OCR

الإصلاح الأساسي في هذه النسخة:

- إلغاء القصاصات الديناميكية التي كانت تفشل بعد ضغط تيليجرام للصورة.
- قراءة الصورة كاملة بمحركي OCR.Space 1 و2 فقط.
- استخراج الرقم الوحيد المكوّن من 9 أرقام، مع استبعاد التاريخ.
- تقليل استهلاك OCR API وعدد الطلبات.
- زر إعادة القراءة يستخدم نفس الطريقة الثابتة.

بعد النشر افتح `/api/set_webhook` مرة واحدة.
