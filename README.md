# Fr3oon Helper Bot V19 — Admin Control

هذه النسخة مبنية على V18، مع الحفاظ على منطق قراءة البطاقات المستقر دون تغيير.

## الجديد
- زر **💬 تواصل مع الأدمن** في رسالة ترحيب العضو الجديد، يفتح مباشرة: `@Mofr3oon`.
- أمر `/admin` يعرض نفس زر التواصل.
- لوحة إدارة سريعة للأدمن بالرد على رسالة العضو وكتابة `/mod`.
- أزرار لوحة الإدارة:
  - ⚠️ إنذار
  - 🔇 كتم 10 دقائق
  - 🚫 حظر فوري
  - 🗑 حذف الرسالة
  - ✅ فك الكتم
  - ♻️ تصفير الإنذارات

## أوامر الأدمن المباشرة
كل أمر يُستخدم **بالرد على رسالة العضو**:

- `/mod` — فتح لوحة الإدارة بالأزرار.
- `/warn سبب المخالفة` — إضافة إنذار يدوي.
- `/mute 10` — كتم 10 دقائق، ويمكن تغيير الرقم.
- `/unmute` — فك الكتم.
- `/ban سبب الحظر` — حظر فوري.
- `/unban` — فك الحظر.
- `/resetwarn` — تصفير إنذارات العضو.
- `/del` — حذف رسالة العضو.

## مثال سريع
1. اعمل Reply على رسالة العضو.
2. اكتب `/mod`.
3. اضغط **إنذار** أو **كتم** أو **حظر فوري**.

## التواصل مع الأدمن
المتغير:

`ADMIN_CONTACT_USERNAME=Mofr3oon`

اكتب اسم المستخدم بدون علامة `@` لو أردت تغييره لاحقًا.

## الصلاحيات المطلوبة للبوت
فعّل:
- Delete messages
- Ban users / Restrict members

## النشر
1. استبدل ملفات المشروع.
