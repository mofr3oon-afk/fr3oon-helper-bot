# Fr3oon Helper Bot - V7 OCR

النسخة دي مخصصة لقراءة **رمز الاسترداد من الصورة نفسها**.

## الجديد
- البوت يحاول يقرأ الكود من الصورة تلقائيًا.
- يرد تحت الصورة بـ:
  - اسم الشخص (من اسم حسابه في تيليجرام)
  - رمز الاسترداد بشكل قابل للنسخ
  - تاريخ الصورة/وقت الإرسال
  - تاريخ انتهاء الكود بعد 3 أيام
- لو الصورة غير واضحة والبوت لم يستطع استخراج الكود، يحذفها ويرسل تنبيه للمستخدم.
- ما زال مستثني منشورات القناة المرتبطة حتى لا يتعطل نظام التعليقات.

## دقة القراءة
يوجد طريقتان:
1. **OCR Space API** (أفضل دقة) ← ضع `OCR_SPACE_API_KEY` في متغيرات البيئة.
2. **Tesseract محلي** كحل احتياطي.

## متغيرات البيئة المهمة
- `OCR_FROM_IMAGE=true`
- `PHOTO_EXPIRY_DAYS=3`
- `OCR_PREFER_CLOUD=true`
- `OCR_SPACE_API_KEY=`

## ملاحظات مهمة
- اسم الشخص يُؤخذ من اسم حسابه في تيليجرام، لأنه أدق من محاولة قراءته من الصورة.
- لو OCR Space API غير موجود، البوت سيستخدم Tesseract فقط، ودقته تعتمد على جودة الصورة.
- لو أردت أفضل نتيجة، اجعل الصورة كاملة وواضحة.

## النشر
ارفع الملفات واعمل Deploy على Vercel.
بعدها افتح:
`/api/set_webhook`
مرة واحدة لإعادة ضبط الويبهوك لو لزم.
