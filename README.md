# Fr3oon Helper Bot V12 — Polished Cards

التحديثات الجديدة:
- زر **📋 نسخ الكود** لنسخ رمز الاستبدال مباشرة.
- زر **🔄 إعادة القراءة** لصاحب الصورة أو الأدمن.
- زر **✅ تم الاستبدال** مع إغلاق البطاقة بعد الاستخدام.
- تنسيق رد مختصر وأنظف.
- رسالة فشل القراءة أصبحت صغيرة ولا تحذف الصورة؛ يمكن إعادة المحاولة من الزر.
- لو المستخدم كتب في الكابشن:
  - `معايا: ...`
  - `عايز: ...`
  فالبوت يعرضهما داخل بطاقة التبادل.
- لا يوجد زر تواصل مع الناشر.
- منشورات القناة المرتبطة تظل مستثناة حتى تعمل التعليقات طبيعيًا.

بعد رفع النسخة وعمل Redeploy افتح:
`/api/set_webhook`
مرة واحدة.
